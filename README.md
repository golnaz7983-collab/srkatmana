# شرکت بینا — نسخه بازی

سامانه فارسی راست‌چین برای بازی مدیریت ملک: جست‌وجو با کد اختصاصی، ثبت ملک، فهرست فروش، درخواست خرید و فروش، تأیید مدیر و سابقه تغییر نام مالک درون بازی.

## پایگاه داده و مدیر
سایت به پروژه Supabase متصل شده است. جدول‌ها و سیاست‌های RLS در پروژه ساخته شده‌اند. برای فعال کردن ورود مدیر:

1. وارد داشبورد Supabase شوید و پروژه بالا را باز کنید.
2. از **Authentication → Users → Add user** یک کاربر مدیر بسازید؛ ایمیل و رمز را خودتان انتخاب کنید و ایمیل را در صورت نیاز تأییدشده قرار دهید.
3. کاربر ساخته‌شده را در SQL Editor با این دستور مدیر کنید؛ مقدار ایمیل را با ایمیل همان کاربر جایگزین کنید:
   `update auth.users set raw_app_meta_data = coalesce(raw_app_meta_data, '{}'::jsonb) || '{"role":"admin"}'::jsonb where email = 'YOUR-ADMIN-EMAIL';`
4. از سایت روی «پنل مدیریت» بزنید و با همان ایمیل و رمز وارد شوید.

**رمز آماده‌ای در کد سایت قرار داده نشده است.** برای امنیت، رمز مدیر در مخزن عمومی ذخیره نمی‌شود. رمز را خودتان هنگام ساخت کاربر تعیین کنید و با کسی به اشتراک نگذارید.

## قابلیت‌ها
- جست‌وجوی ملک با کد اختصاصی
- افزودن، ویرایش، حذف ملک و تغییر وضعیت فروش
- ارسال درخواست خرید و درخواست فروش از سمت بازدیدکننده
- تأیید یا رد درخواست‌ها توسط مدیر
- ثبت تغییر مالک نمایشی در بازی و سابقه تغییرات
- خروجی JSON از داده‌های پنل

## انتشار
در GitHub به [Settings → Pages](https://github.com/golnaz7983-collab/srkatmana/settings/pages) بروید و در بخش **Build and deployment** گزینه **GitHub Actions** را به‌عنوان Source انتخاب کنید. فایل انتشار خودکار از قبل در `.github/workflows/pages.yml` قرار داده شده است. بعد از اجرای موفق workflow، سایت از لینک بالا قابل دسترسی می‌شود.

## نکته
این یک بازی/سامانه نمایشی است. اطلاعات درخواست‌ها در پایگاه داده مشترک ذخیره می‌شوند؛ داده‌های عمومی ملک برای بازدیدکنندگان قابل مشاهده‌اند. فقط کلید publishable در فایل سایت استفاده شده و کلیدهای secret/service-role نباید هرگز داخل سایت یا مخزن قرار بگیرند.
